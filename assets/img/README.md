# 사진 넣는 곳

아래 이름 그대로 저장해서 이 폴더에 넣으면 자동으로 표시됩니다.
파일이 없으면 초록색 배경 무늬가 대신 보이므로, 없어도 사이트는 깨지지 않습니다.

| 파일명                | 쓰이는 곳            | 권장 크기      |
|-----------------------|----------------------|----------------|
| `campus-songdo.jpg`   | 첫 화면 캠퍼스 전경  | 1600 × 900 px  |
| `classroom.jpg`       | 교육 철학 섹션       | 1000 × 1250 px |
| `favicon.svg`         | 브라우저 탭 아이콘   | (이미 있음)    |

## 기존 사이트에서 사진 가져오기 (맥)
1. suereadingclub.clickn.co.kr 에서 원하는 사진을 화면에 띄웁니다
2. 사진을 **바탕화면으로 드래그**하면 저장됩니다
3. 위 표의 이름으로 바꿔서 이 폴더에 넣습니다
