# 이미지 넣는 곳

이 폴더에 사진을 넣고, HTML에서 아래처럼 불러오면 됩니다.

    <img src="assets/img/파일이름.jpg" alt="사진 설명">

## 권장 파일과 크기

| 파일명            | 쓰이는 곳       | 권장 크기      |
|-------------------|-----------------|----------------|
| `logo.svg`        | 상단 로고       | 정사각형       |
| `hero-songdo.jpg` | 첫 화면 배경    | 1920 × 1080 px |
| `classroom-1.jpg` | 수업 소개       | 1200 × 800 px  |
| `campus-songdo.jpg` | 찾아오시는 길 | 1200 × 800 px  |

## 팁
- 사진은 올리기 전에 [squoosh.app](https://squoosh.app) 등에서 압축하세요. 500KB 이하 권장.
- `alt` 설명을 꼭 넣어야 검색 노출과 접근성에 좋습니다.
- 기존 clickn 사이트의 사진은 브라우저에서 사진 위 오른쪽 클릭 → "이미지를 다른 이름으로 저장"으로 내려받아 이 폴더에 넣으면 됩니다.
